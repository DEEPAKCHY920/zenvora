## 🚀 Features

- 💱 **Live Currency Converter** — Real-time exchange rate calculator with 40+ currencies
- 🌍 **160+ Countries Supported** — Send money to destinations worldwide
- 🤖 **AI Support Chatbot** — Instant answers on fees, transfer times, KYC & more
- 🔐 **Security Section** — Highlights RBI regulation, anti-fraud protection & 70+ licences
- 📱 **Mobile-Responsive** — Hamburger menu and adaptive layout for all screen sizes
- 🗂️ **Multi-Page App** — Dedicated pages for Personal, Business, Help, Login & Signup
- 🎯 **SEO Optimized** — Open Graph tags, Twitter Cards, Schema.org JSON-LD & sitemap

## 🛠️ Getting Started

### Option 1 — Open directly in browser (simplest)

Just double-click `index.html` — no setup needed.

### Option 2 — Run with Node.js local server

```bash
# 1. Clone the repository
git clone https://github.com/DEEPAKCHY920/zenvora.git

# 2. Navigate into the project
cd zenvora

# 3. Install dependencies
npm install

# 4. Start the server
node index.js

# 5. Open in browser
# http://localhost:3000
```
